# Chengdu historical sample

This directory is the only sample dataset tracked in Git.

It contains the lightweight Chengdu sample and the historical demonstration code from the
original repository. It is retained for a small runnable example and archival compatibility.

It is **not** the formal KDD experiment and does not implement the frozen conference
reconstruction protocol.

Run from this directory:

```bash
python PWCA.py
```

The formal maintained implementation lives in `../../pwc/` and `../../scripts/`.
Recovered Beijing and Qingdao research data are private and must never be committed.
